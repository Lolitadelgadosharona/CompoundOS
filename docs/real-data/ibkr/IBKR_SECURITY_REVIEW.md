# Security review

IMPLEMENTED: closed GET path patterns; fixed /v1/api base; HTTPS; localhost/127.0.0.1/::1 host restriction; runtime DNS resolves loopback only; TLS certificate+hostname verification; explicit Owner CA file; no verify=False, proxies (trust_env=False), redirects or generic URL from frontend. Bounded response2MB, max10accounts/20pages,120second read budget,10second per-request timeout, no automatic retries/session escalation. One public sync at a time, minimum5seconds between account-discovery attempts; transport at most5rps, below official10rps. Other software accessing gateway can still share pacing quotas.

Default disabled flag; public API has no provider/URL/token override. New local sync/disconnect require same-origin on approved loopback UI/API ports even in Preview. Existing Owner auth remains in non-test deployments; native local test mode is private loopback Owner access, not multi-user production auth. Request body empty model forbids extra credential fields and validation does not echo their values.

Whitelisted normalized fields only stored in sync snapshots; auth cookies/password/token/raw responses discarded. UI masks account refs; no gateway headers/cookies returned. Safe error codes only, bounded uppercase format; no raw gateway exception. Financial snapshots remain sensitive personal data in local PostgreSQL volume, not Git/reports. OS account/files/volumes require Owner security/backup policy before real use. Incidental market prices not retained or made evidence; presence indicator only. No new dependency.

PUBLICLY VERIFIED documentation versus NOT VERIFIED operation: localhost TLS and real account sessions have not been exercised; OAuth encryption/revocation are not implemented because no OAuth used. CPGW handles credentials. Connection identity and sync history immutable; snapshots/status persist across app restart. Local disconnect prevents automatic reads and preserves last-known observations; broker logout/revocation happens manually in official UI/gateway. No unattended polling.

Security testing synthetic: unsafe URLs/path attempts, GET-only/no auth artifacts, future/nonfinite/malformed data, mode mismatch, Owner origin, extra-body rejection, ledger preservation and recommendation block. Tests never replace real account security validation.
